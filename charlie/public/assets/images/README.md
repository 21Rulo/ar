# Imágenes

Placeholders actuales (placehold.co) definidos en `src/js/assets.js`.

Para reemplazarlos: coloca aquí el archivo final y cambia la URL correspondiente
en `IMAGES` (src/js/assets.js) por `/assets/images/<archivo>`. Nombres sugeridos:

- `croco-fiesta.png` → paso 1, corazón en la cabeza
- `croco-bow.png` → paso 3, finger heart
- `photocard-campeche.png` → photocard final (400x600 o similar, vertical)
- `favicon.svg` → ya está reemplazado por un ícono real cuando se tenga
